# CivicConnect

CivicConnect is an AI-powered citizen grievance platform that helps citizens report civic problems and allows authorities to manage and resolve complaints.

## Features

- Citizen registration and login
- Submit civic complaints
- Track complaint status
- AI-based complaint classification
- Priority detection
- Duplicate complaint detection
- Department assignment
- Authority dashboard
- Complaint status management

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- SQLAlchemy
- Scikit-learn

## Project Goal

To make the process of reporting, managing and resolving civic complaints more organized and efficient.
